Research

Efficient AI

I work on making large models cheaper and faster to run at inference time. My current threads are KV cache compression for language models and sparse video generation. The broad goal across both is to cut computation and memory costs while keeping the methods verifiable, so the speedups come with clear evidence that output quality is preserved rather than just a claim.

Reinforcement Learning for Adaptive LLM Agents

I study how reinforcement learning ideas can be used to help large language model (LLM) agents improve from feedback during real use. This work focuses on test time adaptation using reflection, memory, and personalization rather than model fine tuning. As part of the Flipkart–IIT Bombay collaboration, my goal is to build LLM agents that become more reliable and user aware over time.

Other Interests

Beyond my main threads, I'm interested in mechanistic interpretability and am working on a few projects around understanding what goes on inside models. I'm also part of the Bhashini initiative, where I work on training machine translation systems. More recently, I've been exploring agents that generate benchmarks automatically using adversarial techniques.
